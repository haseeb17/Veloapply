## Why this list is different

| Typical GitHub job lists | This list |
| --- | --- |
| Internships and new-grad programs | Mid, senior, staff, and manager roles |
| Volume of postings | Roles on **real ATS career sites**, not LinkedIn Easy Apply |
| Company name + link | **ATS, level, work arrangement, and tailor-needed flags** |
| Student distribution | Built for experienced job seekers who still have to fill Workday |

If you are looking for internships, use [SimplifyJobs/Summer2027-Internships](https://github.com/SimplifyJobs/Summer2027-Internships). If you want new-grad roles, use [SimplifyJobs/New-Grad-Positions](https://github.com/SimplifyJobs/New-Grad-Positions).

## How to use it

1. Pick a role in your category. Prefer 🏠 remote or 🎯 tailor-recommended if that matches how you apply.
2. Open the **company career-site link** — not an aggregator.
3. If the posting is on {{SUPPORTED_ATS}}, [install VeloApply]({{EXTENSION_PLACEHOLDER}}) so the form is filled from your profile. Review every page, then submit yourself.
4. See [ATS.md](ATS.md) for a directory of companies by application platform.

## Contribute

This list stays useful only if people keep it current. If it helps you, star the repo so other experienced job seekers can find it.

- [Add a role](https://github.com/haseeb17/Veloapply/issues/new?template=new-listing.yml)
- [Update a role](https://github.com/haseeb17/Veloapply/issues/new?template=edit-listing.yml)
- [Mark a role inactive](https://github.com/haseeb17/Veloapply/issues/new?template=mark-inactive.yml)

Please read [CONTRIBUTING.md](CONTRIBUTING.md) first. We only accept **currently open**, **experienced** roles on **company career sites**. Internships, Easy Apply links, and duplicate URLs will be closed.

Maintainers approve submissions with the `approved` label. A GitHub Action then updates `data/listings.json` and regenerates this README.
