# Experienced Tech Jobs (2026)

A community-maintained list of **mid-level, senior, staff, and leadership roles** on real company career sites — Greenhouse, Lever, Ashby, Workday, iCIMS, and other ATS boards.

This is not an internship or new-grad list. Simplify already runs that playbook well. This list is for people who are applying as professionals: long Workday forms, custom screening questions, and roles where a tailored application actually matters.

**22 open roles** across **21 companies**. Last generated **2026-08-26**.

This is a starter set. It stays useful if people add roles they actually see on company career sites — then mark them inactive when they close.

## Why this list is different

| Typical GitHub job lists | This list |
| --- | --- |
| Internships and new-grad programs | Mid, senior, staff, and manager roles |
| Volume of postings | Roles on **real ATS career sites**, not LinkedIn Easy Apply |
| Company name + link | **ATS, level, work arrangement, and tailor-needed flags** |
| Student distribution | Built for experienced job seekers who still have to fill Workday |

If you are looking for internships, use [SimplifyJobs/Summer2027-Internships](https://github.com/SimplifyJobs/Summer2027-Internships). If you want new-grad roles, use [SimplifyJobs/New-Grad-Positions](https://github.com/SimplifyJobs/New-Grad-Positions).

## How to use it

1. Pick a role in your category. Prefer 🏠 remote or 🎯 tailor-recommended if that matches how you apply.
2. Open the **company career-site link** — not an aggregator.
3. If the posting is on Workday, Greenhouse, Lever, Ashby, iCIMS, SmartRecruiters, Taleo, and BambooHR, [install VeloApply](https://chromewebstore.google.com/detail/agpginkiklnhcigiecpfemiflebnhnfj?utm_source=github&utm_medium=community_list&utm_campaign=readme) so the form is filled from your profile. Review every page, then submit yourself.
4. See [ATS.md](ATS.md) for a directory of companies by application platform.

## Legend

🏠 Remote · 🏢 Hybrid · 📍 Onsite · 🎯 tailored application recommended (custom screening questions, cover letter, or long Workday form) · 🇺🇸 U.S. citizenship required

Role titles link to the application. 🎯 means the posting has custom questions, a cover letter, or a long ATS flow — a generic resume is a weak fit.

## Contribute

This list stays useful only if people keep it current. If it helps you, star the repo so other experienced job seekers can find it.

- [Add a role](https://github.com/haseeb17/Veloapply/issues/new?template=new-listing.yml)
- [Update a role](https://github.com/haseeb17/Veloapply/issues/new?template=edit-listing.yml)
- [Mark a role inactive](https://github.com/haseeb17/Veloapply/issues/new?template=mark-inactive.yml)

Please read [CONTRIBUTING.md](CONTRIBUTING.md) first. We only accept **currently open**, **experienced** roles on **company career sites**. Internships, Easy Apply links, and duplicate URLs will be closed.

Maintainers approve submissions with the `approved` label. A GitHub Action then updates `data/listings.json` and regenerates this README.

## Product

VeloApply is a review-first job application copilot: autofill, resume tailoring, cover letters, and application tracking. Product details live in [docs/PRODUCT.md](docs/PRODUCT.md). Website: [veloapply.com](https://veloapply.com/?utm_source=github&utm_medium=community_list&utm_campaign=readme).

## Disclaimer

Listings are community-submitted and may close without notice. Always confirm the posting, location, compensation, and work authorization on the employer's site. VeloApply does not run these hiring processes and does not guarantee replies or offers.
