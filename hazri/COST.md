# Hazri — aap ki cost vs school se lena

Yeh 2026 Pakistan bazaar ke typical numbers hain (Lahore / Karachi Hall Road, Hafeez Center). Exact quote app ke **Sell / cost** page se students count daal ke nikalna.

## Aap ko kya kharcha hoga

Software ab ready hai — developer ko alag se 2–4 lakh dena nahi. Recurring cost hardware + SMS hai.

| Cheez | Rate | 300 students, 2 gates |
| --- | --- | ---: |
| RFID / chip cards | PKR 80–120 / card | ~27,000 |
| Printed ID (optional) | PKR 150–220 / card | ~54,000 |
| USB RFID reader | PKR 5,000–12,000 | ~17,000 |
| Tablet / mini display | PKR 25,000–40,000 | ~32,000 |
| Install + fitting | — | ~12,000 |
| SMS in+out (Jazz/Telenor bulk) | ~PKR 0.45–0.70 | ~7,000 / month |
| **Year-1 aap ka kharcha** | hardware + 12 month SMS | **~2.2–2.6 lakh** |

Pehla school thora mehnga padta hai (stock + travel). Doosra school sirf cards + 1 extra reader.

## School ko kitne ka becho

Chhote school (100–200): **1.2–1.8 lakh** first year, phir **8,000 / month**.
Medium (250–500): **1.75–3.0 lakh** year-1 bundle, ya **setup 75k + 12k/month + SMS**.
Bara (800+): **per student PKR 250–400 / year** software+SMS, hardware alag.

**300 students ke liye seedha quote:**

1. **Setup + 3 months** ≈ **PKR 2.3–2.6 lakh** (close karne ke liye best)
2. **Poora year-1 bundle** ≈ **PKR 4.0–4.5 lakh** (hardware + software + SMS)
3. **Per student** ≈ **PKR 900–1,200 / year** agar hardware school khud le

Is par aap ka year-1 profit typically **1.8–2.5 lakh** per school, kyun ke software cost ab almost zero hai.

## Deal kaise close karein

- School ko kiosk page live dikhao (demo cards, bina reader ke).
- Ek parent SMS sample register se padh ke dikhao.
- Hardware 20–30% markup, software high margin, SMS cost+25%.
- 3 month warranty on readers, cards lost = school reprint rate.

Live numbers ke liye app kholo → **Sell / cost**.
